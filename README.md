# سیستم مدیریت رسیدهای واریزی

یک برنامه کامل Node.js برای مدیریت رسیدهای واریزی با پنل ادمین و کاربران معمولی

## ویژگی‌ها

### پنل ادمین
- ورود با نام کاربری و رمز عبور مشخص شده
- امکان افزودن کاربران جدید (نام کاربری و رمز عبور)
- مشاهده کل واریزی‌ها با یک دکمه
- جستجو بر اساس نام دانش‌آموز
- فیلتر بر اساس بازه زمانی (از تاریخ تا تاریخ)
- مشاهده آمار کلی (مجموع واریزی‌ها و تعداد رسیدها)

### پنل کاربران
- ثبت رسید جدید با اطلاعات:
  - نام دانش‌آموز
  - مبلغ واریزی (به تومان)
  - انتخاب تاریخ شمسی
  - روش پرداخت (کارت به کارت یا دستگاه پوز)
  - آپلود تصویر فیش واریزی
- مشاهده لیست رسیدهای خود
- امکان حذف رسیدهای ثبت شده

### طراحی UI/UX
- استفاده از پالت رنگی آبی تیره
- طراحی ریسپانسیو و مدرن
- تقویم شمسی (Persian Datepicker)
- پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)

## راهنمای نصب و راه‌اندازی

### پیش‌نیازها
- Node.js (نسخه 14 یا بالاتر)
- npm (همراه با Node.js نصب می‌شود)

### مراحل نصب

#### 1. دانلود پروژه از گیت‌هاب

```bash
# کلون کردن ریپازیتوری
git clone <URL_REPOSITORY_GITHUB>

# ورود به پوشه پروژه
cd <NAME_PROJECT>
```

یا اگر فایل ZIP را دانلود کرده‌اید:

```bash
# استخراج فایل ZIP
unzip project.zip

# ورود به پوشه پروژه
cd project
```

#### 2. نصب وابستگی‌ها

```bash
# نصب تمام پکیج‌های مورد نیاز
npm install
```

این دستور پکیج‌های زیر را نصب می‌کند:
- express
- sqlite3
- bcryptjs
- jsonwebtoken
- multer
- cors
- express-session

#### 3. اجرای برنامه

```bash
# اجرای سرور
node server.js
```

پس از اجرای موفقیت‌آمیز، پیام زیر را مشاهده خواهید کرد:
```
Connected to SQLite database
Admin user created successfully
Receipts table ready
Server running on http://localhost:3000
```

#### 4. ورود به برنامه

مرورگر خود را باز کنید و به آدرس زیر بروید:
```
http://localhost:3000
```

## راهنمای استفاده

### برای ادمین

1. **ورود به سیستم**
   - نام کاربری و رمز عبور ادمین را وارد کنید
   - روی دکمه "ورود به سیستم" کلیک کنید

2. **افزودن کاربر جدید**
   - در بخش "مدیریت کاربران"
   - نام کاربری و رمز عبور جدید را وارد کنید
   - روی دکمه "افزودن کاربر" کلیک کنید

3. **مشاهده آمار کلی**
   - در بخش "آمار کلی واریزی‌ها"
   - مجموع کل واریزی‌ها و تعداد رسیدها نمایش داده می‌شود

4. **جستجو و فیلتر**
   - نام دانش‌آموز را وارد کنید (اختیاری)
   - تاریخ شروع و پایان را انتخاب کنید (اختیاری)
   - روی دکمه "جستجو" کلیک کنید
   - برای نمایش همه، روی "نمایش همه" کلیک کنید

5. **مشاهده جزئیات رسیدها**
   - تمام رسیدها در جدول نمایش داده می‌شوند
   - برای مشاهده تصویر فیش، روی تصویر کوچک کلیک کنید
   - برای حذف رسید، روی دکمه "حذف" کلیک کنید

### برای کاربران معمولی

1. **ورود به سیستم**
   - نام کاربری و رمز عبوری که ادمین ایجاد کرده را وارد کنید
   - روی دکمه "ورود به سیستم" کلیک کنید

2. **ثبت رسید جدید**
   - نام دانش‌آموز را وارد کنید
   - مبلغ واریزی را به تومان وارد کنید
   - روی فیلد تاریخ کلیک کرده و تاریخ را از تقویم شمسی انتخاب کنید
   - روش پرداخت را انتخاب کنید (کارت به کارت یا دستگاه پوز)
   - روی "انتخاب فایل" کلیک کرده و تصویر فیش را انتخاب کنید
   - روی دکمه "ثبت رسید" کلیک کنید

3. **مشاهده رسیدهای ثبت شده**
   - در پایین صفحه، جدول لیست رسیدها قرار دارد
   - تمام رسیدهای ثبت شده توسط شما نمایش داده می‌شود
   - برای مشاهده تصویر فیش، روی تصویر کوچک کلیک کنید

## ساختار پروژه

```
project/
├── server.js              # کد اصلی سرور Node.js
├── package.json           # لیست وابستگی‌ها

    ├── style.css          # استایل‌ها و طراحی
    └── app.js             # کدهای JavaScript سمت کلاینت
```

## نکات مهم

1. **پایگاه داده:** تمام اطلاعات در فایل `database.sqlite` ذخیره می‌شود. این فایل به صورت خودکار در اولین اجرا ایجاد می‌شود.

2. **تصاویر:** تصاویر فیش‌ها در پوشه `uploads/` ذخیره می‌شوند.

3. **امنیت:** 
   - رمزهای عبور به صورت هش شده ذخیره می‌شوند
   - احراز هویت با JWT انجام می‌شود
   - توکن دسترسی بعد از 24 ساعت منقضی می‌شود

4. **پشتیبان‌گیری:** برای پشتیبان‌گیری، فایل‌های `database.sqlite` و پوشه `uploads/` را کپی کنید.

## عیب‌یابی

### مشکل: خطا در نصب پکیج‌ها
```bash
# پاک کردن cache npm
npm cache clean --force

# حذف node_modules و reinstall
rm -rf node_modules package-lock.json
npm install
```

### مشکل: پورت 3000 اشغال است
```bash
# تغییر پورت در server.js
const PORT = 3001; // یا هر پورت دیگر
```

### مشکل: عدم نمایش تقویم شمسی
- اطمینان حاصل کنید که به اینترنت متصل هستید (CDN برای کتابخانه‌ها)
- کش مرورگر را پاک کنید
